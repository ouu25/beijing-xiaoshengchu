# 贡献指南

感谢你考虑为这个项目贡献信息。每一条经过验证的数据，都能帮助更多家长获得平等的信息。

## 贡献方式

### 方式一：提交 Issue（最简单）

如果你有某所学校的信息想分享，直接在 GitHub 上提交一个 Issue：

1. 点击仓库页面的 "Issues" → "New Issue"
2. 选择对应的模板（学校信息 / 渠道信息 / 考试信息 / 时间线更新）
3. 按模板填写信息
4. 提交后我们会核实并录入

### 方式二：提交 Pull Request（适合有技术背景的贡献者）

1. Fork 本仓库
2. 在 `data/` 目录下修改或新增 JSON 文件
3. 确保格式符合 [数据字典](data-dictionary.md) 的规范
4. 提交 PR 并简要说明信息来源

### 方式三：匿名反馈

如果你不方便公开提交，可以通过匿名表单提交信息（链接待补充）。

## 贡献规范

### 必须遵守

- **不包含任何个人身份信息**：姓名、电话、微信号、具体住址等一律不得出现
- **标注数据来源和可信度**：每条信息都需要标注 `source_confidence`
- **区分事实和推测**：如果是推算或传闻，必须标注为 `estimated` 或 `reported`
- **更新日期**：修改数据后更新 `last_updated` 字段

### 建议遵守

- 尽量提供多个信息来源
- 如果修正了已有数据，说明修正原因
- 对于敏感信息（如点招渠道），使用客观中性的描述

### 绝对不要

- 公开任何真实姓名、联系方式
- 发布未经脱敏的对话截图
- 对学校或个人进行主观攻击
- 发布明确的商业推广内容

## 信息验证流程

1. 新提交的信息默认标记为 `reported`（待验证）
2. 维护者会尝试交叉验证
3. 获得 3 个以上独立来源确认后升级为 `verified`
4. 来自官方渠道的信息直接标记为 `official`

## 数据格式

所有数据文件使用 JSON 格式，字段定义见 [数据字典](data-dictionary.md)。

文件命名规则：
- 学校：`{区拼音}_{校简称拼音}.json`（如 `haidian_rdfz.json`）
- 渠道：`{school_id}_{year}.json`（如 `haidian_rdfz_2025.json`）
- 考试：`{school_id}_{year}_{序号}.json`（如 `haidian_rdfz_2025_01.json`）
- 时间线：`{区拼音}_{year}.json`（如 `haidian_2025.json`）
