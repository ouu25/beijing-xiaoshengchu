# 北京小升初信息公开计划

> 让每个家长都能平等获取小升初信息，打破信息垄断。

## 这是什么

一个开源的、结构化的北京小升初信息数据库。覆盖海淀区和西城区核心学校的入学渠道、考试信息、年度时间线，以及家长经验。

所有数据公开透明，任何人可以查阅、补充、纠正。

## 为什么做这个

北京小升初的信息生态极度不透明：

- 核心学校的点招、MD 等渠道从不公开，家长只能靠打听
- 培训机构靠信息差赚钱，免费信息真假混杂
- 每年政策微调，但没有人系统追踪变化
- 家长之间信息严重不对等，焦虑被人为放大

这个项目的目标是：**把分散在家长群、机构直播、小红书里的碎片信息，整理成结构化、可验证、可检索的公开数据。**

## 数据结构

```
data/
├── schools/          # 学校档案（每校一个 JSON 文件）
├── channels/         # 入学渠道记录
├── exams/            # 考试与真题回忆
└── timeline/         # 年度时间线事件
```

详细的数据字段说明见 [数据字典](docs/data-dictionary.md)。

## 信息治理原则

1. **事实优先** — 只记录可验证的事实，不做主观排名
2. **多源交叉** — 关键信息需至少两个独立来源确认
3. **脱敏保护** — 不公开具体联系人，不暴露信息来源身份
4. **独立运营** — 不接受机构赞助，不做付费推荐

## 数据可信度标签

每条数据都标注来源可信度：

| 标签 | 含义 |
|------|------|
| `official` | 学校或教委官方公示 |
| `verified` | 3个以上独立家长来源交叉确认 |
| `reported` | 1-2个家长来源，待更多验证 |
| `estimated` | 基于历年数据或间接推算 |

## 如何贡献

我们欢迎任何人补充或纠正信息：

1. **提交 Issue** — 提供你知道的信息，我们核实后录入
2. **提交 Pull Request** — 直接修改数据文件，按格式提交
3. **匿名反馈** — 如果不方便公开，可以通过 [匿名表单]() 提交

贡献时请注意：
- 不要包含任何个人身份信息（姓名、电话、微信号等）
- 尽量说明信息来源和时间
- 如果是传闻，请标注为 `reported`

## 免责声明

本项目所有信息仅供参考。数据来源于公开渠道和家长众包，可能存在偏差。入学决策请以各区教委和学校官方通知为准。
