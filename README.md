# 北京小升初升学索引

北京市海淀区、西城区小升初学校信息、入学渠道、成绩数据与备考经验的结构化整理。

**网站**：[xiaoshengchu.org](https://xiaoshengchu.org)

## 内容覆盖

- **学校档案** — 海淀、西城两区36所学校的基本信息、班型、高考/中考成绩数据
- **入学渠道** — 各校入学途径、选拔方式、透明度标注
- **考试记录** — 历年选拔考试形式、科目、难度、回忆题整理
- **年度时间线** — 2026年度升学关键节点与时间安排
- **备考指南** — 政策解读、竞赛体系、申请策略

## 数据来源与可信度

数据来自区教委官网、学校公告及家长社区公开信息。每条数据标注可信度等级：

| 标签 | 含义 |
|------|------|
| `official` | 学校或教委官方公示 |
| `verified` | 多个独立来源交叉确认 |
| `reported` | 少量来源，待更多验证 |
| `estimated` | 基于历年数据或间接推算 |

## 数据结构

```
data/
├── schools/          # 学校档案
├── channels/         # 入学渠道记录
├── exams/            # 考试与真题回忆
└── timeline/         # 年度时间线事件
```

详细字段说明见 [数据字典](docs/data-dictionary.md)。

## 参与贡献

欢迎补充或纠正信息：

1. **提交 Issue** — 提供信息，核实后录入
2. **提交 Pull Request** — 直接修改数据文件
3. **邮件联系** — contact@xiaoshengchu.org

贡献时请注意：
- 不要包含任何个人身份信息（姓名、电话、微信号等）
- 尽量说明信息来源和时间
- 未经验证的信息请标注为 `reported`

## 免责声明

本项目所有信息仅供参考，不构成升学建议。入学政策每年调整，请以各区教委和学校当年官方通知为准。
