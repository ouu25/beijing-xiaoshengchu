备考指南

基于近五年上岸案例和公众号信息整理的备考路径建议，仅供参考。

英语：KET / PET / FCE

PET 卓越级是小升初的竞争力基准线。六小强上岸学生普遍 PET-FCE 水平。

早培复选英语约 FCE 难度，考中国传统文化（十二生肖、中医等）。机构活动的英语部分介于 KET-PET 之间（普通场）到 FCE（高端场）。

建议：三年级开始备考 KET，四年级考 PET，五年级冲 FCE。目前北京考位供应已恢复正常，不需要出京赶考。

数学竞赛

数学竞赛是小升初含金量最高的敲门砖。核心杯赛：

• AS（奥数联赛）：一等奖是六小强硬通货，二等奖也有较强竞争力

• 华杯赛：老牌赛事，一二等奖含金量高

• 希望杯：一等奖有参考价值

• YCB / 大师赛：部分学校认可

从上岸简历看，AS 一等 + PET/FCE 是最常见的六小强上岸组合。

市三好 / 区三好

市三好是硬通货：101中学市三好可直升本部高中；筛简历时市三好优先级最高。

三年区三好是很多学校筛简历的基本门槛。上地实验等校活动参与条件：市三好+其他，或三年区三好+杯赛奖项。

从上岸案例看：有市三好基本都能拿到活动机会；无三好但有 AS 一等也能上岸，但选择面窄。

金帆 / 金鹏 / 金奥

2025年市教委认定：金帆艺术团 126个、金鹏科技团 90个、金奥运动队 63个。

拥有金帆团的中学，中招时可面向全市招收特长生。金帆金鹏对应的学校在"学校档案"中已标注。

注意：2019年起小升初已取消特长生入学，金帆金鹏主要影响中考升学（初升高），但学校社团实力仍是衡量学校综合水平的参考。

时间线：五六年级备考节奏

四年级：奥数系统学习、KET/PET 备考、争取区三好

五年级上：冲刺 AS/华杯一等、考 PET 或 FCE、参加早培/2+4 报名

五年级下-六年级上：机构活动/杯赛出成绩、准备简历（证书+荣誉+自荐信）、期末考试全力以赴（是重要筛选参考）

六年级 1-3 月：投递简历、参加学校开放日和活动

六年级 4-5 月：政策发布、信息采集、MD 密集期

六年级 6 月：登记入学志愿填报、派位结果

六年级 7 月：分班考试（非常重要，影响实验班分配）

上岸简历参考（2021年部分案例）

• AS一等 → 十一 2+4

• AS二等 + PET → 十一龙樾

• 三年区三好 + AS二等 → 十一

• 市三好 + PET + AS一等 → 拿到五张小强票，选清华附

• 市三好 + PET + DSS银 + 华一 → 清华附

• 市三好 + 班长 → 十一龙樾

• 无三好 + AS二等 → 十一晋元

来源：小倪聊升学（2021年数据），每年标准可能调整

简历制作要点

封面：不要只写"学生简历"四个字。建议放孩子阳光照片 + 核心奖项（如市三好）+ 父母联系方式，方便学校快速筛选。

核心模块：基本信息（学籍、户籍、性别必填）→ 综合素质评价手册成绩（4-6年级各科，学校最看重）→ 荣誉奖项（三好、红领巾、班干部）→ 竞赛证书 → 其他特长。

特别提醒：父母联系方式写手机（不要座机），提醒爸爸注意接陌生电话——往年有把学校通知当广告挂掉的。

面试常见问题

问孩子（常规）：评价自己和父母、兴趣爱好、报了哪些课外班、班级职务、英文自我介绍

问孩子（主观）：和同学发生矛盾如何解决、如何安排假期、喜欢的书为什么喜欢、长大后想做什么

问孩子（考试）：口述数学题（奥数/九宫格/应用题）、背含金量高的古诗词、英语阅读后回答提问、小组合作完成项目

问家长：评价孩子优缺点、平时谁辅导孩子、我们学校是否首选、目前有几个选择

注意：人大附体系学校面试通常要求父母双方都到场。

六小强 DZ 渠道差异

人大附：五下早培入营表现 + 机构高端班名单匹配，不太看简历

清华附：依靠部分机构和自身"顶牛"（培训机构）组织活动，战线长

十一：重视 DSS 活动成绩 + 自身网报，网报时三好和校外活动获奖都有参考价值

101：有自己的坑班选拔，也关注 DSS，但更认可自身选拔结果

北大附：偏好信息学，有信息学独立活动选拔 + 线上线下活动

首师附：最不好把握规律，可能看周边小学活动、简历、信息学、DSS 等多种渠道

来源：2024初中入学白皮书，每年渠道可能调整

志愿填报策略

核心原则：一派和二派必须联动考虑。先看二派学区内最差的学校能否接受，再决定一派的保守程度。

逆向思维：同层次学校内避开热门。招生计划多的学校不一定好进（填报人数可能更多），招生计划少的反而可能竞争小。

有 MD 的情况：小强级别 MD 建议按学校要求填一志愿；非小强 MD 如果不是首选，可以一志愿冲更高再等补录。

补录节点：一派结果出来后第一批补录（学校自己名单）→ 出确认码后第二批补录（有人放弃腾出名额）。主动高频联系学校争取。

海淀入学方式：一派与二派

一派（登记入学）：面向全区或特定区域招生，含公办登记入学、按比例对口直升、公办寄宿、民办校四种方式。可填1-10个志愿（可混合填报），电脑随机派位，未中不强制分配。六小强在此阶段面向全区招生。DZ/MD 也在此阶段完成确认。

二派（学区派位）：按小学所属学区对应的初中，必须全部填满志愿（不重不漏），电脑随机派位。轮空会被强制分配到有剩余学位的学校。这是最后的兜底环节。

关键策略：一派和二派必须联动考虑。先看二派学区内最差的学校能否接受，再决定一派的保守程度。没有保底的家长，应在一派阶段用中间志愿拦截一所比学区最差好的学校。

西城入学方式

西城是统一填报所有志愿批次，分批录取。5月下旬一次性填报全区派位、特色校、寄宿校、学区登记、学区派位等所有志愿，6-7月分批次公布录取结果。

批次顺序：全区派位 → 特色校/寄宿校 → 对口直升 → 学区登记入学 → 学区派位。前面批次录取后不再参加后续批次。学区派位是最终兜底。

2025年变化：学区登记名额从50人统一调整到30人；新增3所学校参与全区派位（八中四存100人、161广安160人、铁二中右安门240人）。

1+3 培养实验项目

初二结束时，学生可报名参加高中组织的1+3选拔。录取后中考成绩不再作为升学依据，初三直接转入录取高中，完成1年初三+3年高中的贯通培养。

报名条件：具有北京市普通高中升学资格 + 同一学校连续两年初中学籍的初二学生。每人只能报一所区级实验校（可另报一所市级）。

名额分配：最多70%给本校初中部，至少30%面向外校。跨校竞争非常激烈。

海淀2024年有1+3项目的学校（22所区级）：五十七中、人翠、海淀实验、交大附中（东校区，工程班+美术班）、理工附中（多语种实验班，与北外附中合办）、育英中学、首师大一分校、101双榆树/矿大/石油分校等。

成果参考：57中1+3实验班高考均分652+；交大附工程项目班首届全部考入985；海淀实验钱学森班（含1+3学生）650+4人，600+31人。

退出机制：可在初三学业水平考试报名前退出，回原初中参加中招，但不能参加校额到校批次录取。

西城：①学区登记名额从50人调整到30人；②新增3所学校参与全区派位（八中四存100人、161广安160人、铁二中右安门240人）。
